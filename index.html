Sizes are the model weights for both stems; the browser download is ~1.33× larger because weights ship as base64. SI-SDR on 16 held-out excerpts.

Why the gaps: the engine ships int8 weights only, so fp32 builds are listed for reference but not downloadable. HDMC is a conv + transformer hybrid — a different architecture that would need its own JavaScript engine, and 84 MB even at int8. And HDMC has zero subnormal weights and zero dead rows, so the pruning that saves 15 % on UMX20 has nothing to remove there.

What is running

  • Three int8 models, loaded on demand — only the one you pick is downloaded.
  • The built-in demo clip is a 10 s excerpt, fetched on demand like a model.
  • STFT, inverse STFT, ratio masking and 6 s overlap-add, all in plain JavaScript.
  • No WebAssembly, no SIMD, no GPU — a deliberate worst case for speed.
  • The HDMC teacher (334 MB) is not here: it is a different architecture (conv + transformer hybrid) and would need a separate JavaScript engine.
