How to read this

• All fine-tunes start from the shipped PCD base model and use 30 % real PCD excerpts per batch as rehearsal, lr 1e-4, batch 8, 6 s chunks, 16 epochs.
• “+ unison / + timbre / + octave” are cumulative dataset additions, not alternative models: each one keeps everything the previous one had.
• SI-SDR on the synthetic sets is measured against the generator's ground-truth stems; on PCD it is measured against the reference stems shipped with the dataset.
• Model size is the two heads together, fp32.
